If it does not work

535 5.7.139 Microsoft 365 has basic authentication switched off for that mailbox. It is not the password: move to OAuth2 — three settings in .env, documented in the operations manual, §8.3.
AADSTS7000215 The client secret is wrong, or has expired. They do expire, and the day one lapses mail stops going out without the settings having changed.
AADSTS700016 The application id or the tenant id does not match a registration in that tenant.
Token accepted, send refused The application has a token but no right over the mailbox. In Exchange Online PowerShell: Add-MailboxPermission for the app's service principal.
Sent, never arrived Not an SMTP problem. SPF, DKIM and DMARC for {{ from_domain }}, and the recipient's junk folder.
Timed out Outbound port {{ port }} is blocked, which some hosts do by default. Ask the provider rather than changing anything here.
